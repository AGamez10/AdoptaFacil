## CI/CD

- Un solo workflow, `.github/workflows/ci.yml`: jobs `quality` (lint, typecheck, build, unit) y `rls-no-leak` (migraciones + integración). Corre en `push` a `main` y en `pull_request`.
- **Estado en la línea base: ROJO.** La única ejecución en este repo (run 37638211167, commit `48cabad`) falló en `quality` por BLD-002. Es decir, la entrega se hizo con `main` en rojo.
- Gates exigidos por §7.6 que **no existen**: gitleaks, auditoría de dependencias, semgrep/regla de SQL injection, deriva de esquema, guarda de drivers fake en producción, postura RLS al arrancar, aislamiento HTTP A-vs-B por recurso, e2e, build de imágenes.
- `CODEOWNERS` usa marcadores `@sebastian` / `@fabian` que no son usuarios reales: GitHub no puede pedir revisión. Sin protección de rama verificable desde aquí.
- Plantilla de PR presente (`.github/PULL_REQUEST_TEMPLATE.md`); se usará en los PR de este proyecto.
